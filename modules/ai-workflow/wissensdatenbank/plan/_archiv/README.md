# Plan-Archiv

Abgeschlossene (`done`) Plaene hierher verschieben: kompletter Ordner
`plan\<name>\` nach `plan\_archiv\<name>\`. Nicht loeschen - die Historie
(plan.md, status.md, worker-/handoff-Dateien) bleibt erhalten.

- Im Plan-Index (`plan\plan.md`) den Eintrag auf `done` setzen und den Ordnerpfad
  auf `_archiv\<name>` anpassen (oder die Zeile ins Archiv-Wissen uebernehmen).
- Aktive Plaene bleiben direkt unter `plan\`; nur fertig umgesetzte wandern hierher.
