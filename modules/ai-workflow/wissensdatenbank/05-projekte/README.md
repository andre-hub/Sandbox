# Projekte

`README.md` und `_vorlagen` sind neutraler Modulinhalt. Jeder andere direkte
Unterordner steht fuer eine lokale Firmeninstanz und wird vom Installer erhalten.

Kopiere `_vorlagen\firma` nur bewusst nach `<Firma>` und ergaenze dort ausschliesslich
freigegebene lokale Inhalte. Keine Secrets oder personenbezogenen Daten in diese
auslieferbare Vorlage schreiben.

Details: `projekte.md`.
