# Vorlage: Allgemeines Projekt

Auslieferbare, neutrale Vorlage fuer ein **allgemeines (firmenneutrales) Projekt**
unter `05-projekte\<projekt>\`. `05-projekte\` ist bewusst NICHT firmengebunden.

Firmenspezifisches Wissen gehoert stattdessen in einen eigenen Hauptordner
`C:\wissensdatenbank\<Firma>\` (Vorlage: `06-vorlagen\firma\`), nie unter `05-projekte\`.

Nutzung: `_vorlagen\projekt\` bewusst nach `05-projekte\<projekt>\` kopieren und mit
freigegebenen Inhalten fuellen. Keine Secrets oder personenbezogenen Daten.
